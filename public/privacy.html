Retour à Notes

Vos données restent les vôtres.

Notes est un projet personnel open source. Il ne possède pas de base de comptes ni de serveur qui reçoit le contenu de vos salons.

Sur votre appareil

Notes vérifie votre identité avec Google. Les messages, les noms des salons et les fichiers restent chiffrés avec AES 256 GCM dans IndexedDB. La clé de déchiffrement est conservée séparément sur l’appareil et associée au compte Google. Aucun mot de passe Notes ni verrouillage automatique n’est prévu. Se déconnecter ferme la session, mais ne supprime pas la copie locale.

Dans Google Drive

Drive reste facultatif. Lorsque vous l’activez, les objets chiffrés et la clé de l’espace sont enregistrés dans le dossier privé d’application de votre compte. Cela permet à vos autres appareils autorisés de retrouver vos notes sans nouveau mot de passe. Google peut techniquement accéder à la clé : cette version ne promet pas un chiffrement empêchant Google de lire les données. Notes ne possède pas de serveur recevant vos notes ou votre clé. Les jetons d’accès Google restent en mémoire.

Exports

Aucun mot de passe Notes ni parcours de migration n’est proposé. Les données des anciennes versions d’essai ne sont pas reprises. Les exports récents contiennent la clé et doivent rester privés : une personne possédant le fichier peut récupérer son contenu.

Versions et suppression

Supprimer un message le retire du coffre courant. D’anciennes versions chiffrées peuvent subsister sur le cloud. Cette version ne propose pas de purge complète de l’historique. Supprimer la copie de cet appareil ne supprime pas les données cloud.

Services externes

Notes ne contient ni publicité ni outil d’analyse d’audience. Le chargement du site contacte son hébergeur. Lorsque la connexion Google est configurée, son script de connexion est chargé pour permettre l’ouverture de la fenêtre de consentement. La connexion et le stockage utilisent les services Google. Sur Windows, le site consulte GitHub pour proposer le téléchargement du dernier installeur. Ces services appliquent leurs propres règles de confidentialité.

Limites

Le code de chiffrement n’a pas été audité indépendamment. Un appareil compromis ou une version modifiée de l’application peut lire un coffre ouvert. La perte simultanée de la clé locale, de la clé sur Drive et des sauvegardes rend les données irrécupérables.
